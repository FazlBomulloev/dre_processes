# ВПЦ + RGS — платформа по образцу PharmDash

Пакет для старта разработки в Claude Code. Внутри всё, что было решено в
чатах по дашборду «Предложения заводов» (ВПЦ) и дашборду регистрации в
Азербайджане (RGS): план, описание данных, дизайн и примеры файлов.

## Что строим

Одно веб-приложение с входом по логину и правами доступа. Данные
загружаются Excel-файлами через интерфейс.

| Модуль | Что показывает | Источник |
|---|---|---|
| ВПЦ · общий | все предложения заводов: таблица, заводы, страны, воронка, детализация | выгрузка ВПЦ (.xlsx) |
| ВПЦ · рынок | полный дашборд одного рынка «для какой страны ищем»; первым — Азербайджан (AZ) | та же выгрузка ВПЦ с фильтром по стране |
| RGS | регистрация препаратов по рынкам: обзор и реестр; первым — Азербайджан | трекер RGS (.xlsx), формат ещё уточняется |

## Состав архива

```
CLAUDE.md                 инструкция для Claude Code (начать с неё)
README.md                 этот файл
docs/PLAN.md              архитектура, вход и права, этапы работ
docs/DATA_VPC.md          формат выгрузки ВПЦ, статусы, расчёты
docs/DATA_RGS.md          формат трекера RGS, статусы, расчёты
docs/DESIGN.md            экраны, токены стиля, как открыть дизайн
docs/DECISIONS.md         что решено в чатах и что ещё открыто
design/vpc/*.dc.html      дизайн ВПЦ: 4 экрана + 4 экрана детализации
design/rgs/*.dc.html      дизайн RGS: «Обзор» и «Препараты»
design/screenshots/*.png  скриншоты всех экранов
examples/vpc_export_example.xlsx   синтетическая выгрузка ВПЦ (240 строк)
examples/rgs_tracker_example.xlsx  трекер RGS Азербайджан (69 позиций)
```

## Как начать

1. Распаковать архив в пустую папку проекта и открыть её в Claude Code.
2. Написать: «Прочитай CLAUDE.md и начни с шага 0».
3. Claude Code изучит PharmDash, перескажет, что берёт оттуда, и
   предложит первый этап из `docs/PLAN.md`.

## Посмотреть дизайн

```bash
cd design
python -m http.server 8000
```

Открыть http://localhost:8000/vpc/Main.dc.html или
http://localhost:8000/rgs/Main.dc.html. Экраны кликабельные, данные в
дизайне ВПЦ демонстрационные, в RGS — из реального трекера на 13.11.2026.
