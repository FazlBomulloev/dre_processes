# Решения и открытые вопросы

## Решено

### Общее
- Один проект по образцу PharmDash (тот же стек и стиль), с входом и
  правами. Позже модули могут войти в PharmDash.
- Данные загружаются Excel-файлами через интерфейс.
- Реальная выгрузка ВПЦ приватная: только сервер компании, без внешних
  сервисов.

### ВПЦ
- Формат выгрузки окончательный.
- Статус берётся из «Статус Пд». «Общий Статус» не используется.
- Расшифровка статусов — из ВПЦ (DATA_VPC.md). Этапа СЦ нет. NКк —
  «есть контракт, не выбран для портфеля».
- Цена только за упаковку; порядок: Согл.Цена → Наша цена 2 → Наша цена 1
  → Цена в USD, с выбором колонки в меню.
- Метки «лучшая» нет; есть «+X% к мин.».
- Блока «Все предложения по продукту» в карточке предложения нет.
- «Только с ценой» — среди основных фильтров.
- Графиков на экране «Предложения» нет; аналитика на отдельных экранах.
- Нужны экраны по заводам, странам, воронке и детализация по клику.
- ВПЦ · рынок: отдельный полный дашборд рынка, первым — Азербайджан.

### RGS
- Пока формат трекера не окончательный.
- Дата подачи: BI, если пусто — AJ.
- План РУ: BL (майский план) + 2 месяца.
- Опоздание подачи не сдвигает план РУ; показывается в «план/факт».
- dhp1 — оплачена первичная экспертиза, dhp2 — оплачена
  специализированная.
- Стоп — отдельно, в цифры не входит. Оплаты не показывать.
- Разбивки IZ/ЧС на обзоре нет; фильтр по категориям есть.
- «Когда получим РУ» — по месяцам, клик → панель со списком.
- Позиции с листа IN — новые, в «Готовятся».

## Открыто — спросить у пользователя

1. **Кк в ВПЦ**: часть «В работе», отдельная группа «Контракт» или
   «Результат»? В дизайне — отдельная группа, в первом HTML-дашборде —
   «В работе». Сделать одинаково везде после ответа.
2. **Ценовой индекс завода**: подходит ли формула «средний +X% к лучшей
   цене по его продуктам»?
3. **Минимальная цена**: учитывать ли остановленные (S) и NКк
   предложения или только активные?
4. **Причины остановок**: откуда брать (последний комментарий по
   ключевым словам?) и какой список причин.
5. **Права на уровне строк**: нужен ли режим «БДМ/аналитик видит только
   свои предложения»? Как связать пользователя с именем в выгрузке?
6. **Роли**: подходит ли набор owner / admin / manager / analyst /
   viewer и кто может загружать файлы.
7. **RGS «Что мешает»**: делить ли на «долгосрочная подготовка» (ITOGAST,
   VEGADERM, FOBOS, FINOTERB крем) и «проблемные» (ZHASMED, ERGONEX,
   IMMUJEN, PERMANEO DUAL, MYOMEX)?
8. **RGS формат**: окончательный вид трекера (пользователь пришлёт).
9. **ВПЦ · рынок + RGS**: показывать ли на странице рынка карточку RGS
   этого рынка.
10. **Хранение истории**: сколько снимков выгрузки держать (для динамики
    «сменило статус»).
11. **Где разворачивать**: тот же сервер, что PharmDash (отдельный
    домен/поддомен), или другой.
12. Заголовки ВПЦ в примере восстановлены по чату — нужен настоящий
    пример из 2–3 строк для сверки.
