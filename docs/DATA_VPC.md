# Выгрузка ВПЦ

Формат окончательный: так выглядит реальная выгрузка. Реальный файл
приватный и в проект не передаётся. `examples/vpc_export_example.xlsx` —
синтетический файл той же структуры: заголовки восстановлены по чату и
примеру из двух строк, значения выдуманы. Перед этапом 2 попросить у
пользователя настоящий пример из 2–3 строк и сверить заголовки.

## Где искать данные

- Лист: первый, в котором в первых 30 строках есть ячейка «Дженерик».
  Эта строка — заголовки, всё ниже — данные.
- Около 20 000 строк, 62 колонки (A–BJ).

## Особенности заголовков

Заголовки сравнивать после нормализации: обрезать пробелы, схлопнуть
повторные пробелы, без учёта регистра.

| Проблема | Пример | Что делать |
|---|---|---|
| Опечатки | «Проиводитель» | словарь синонимов |
| Пробел в начале/конце | «Форма », « Дата Создания» | strip |
| Разорванный заголовок | «Д», «ата», «посл.», «комм.» | это дата последнего комментария, счётчик и валюта: колонку валюты искать по значениям (USD/EUR), дату — по типу |
| Дата текстом | «Дата ПО» = `'2026-10-21 00:00:00'` | парсить строку |

не подтвердил.

## Статусы (колонка «Статус Пд»)

Расшифровка от пользователя из самой ВПЦ:

| Код | Значение |
|---|---|
| Вб | Выборка (в старых данных бывает «ВП») |
| ПО | Прогноз объёма |
| АЦ | Анализ цен |
| ПцКк | Процесс контракта |
| Кк | Контракт |
| ПцР | Процесс регистрации (в датах этапов — 6НПР, 7КД) |
| Р | Получено регистрационное удостоверение |
| Р- | Получено РУ для БАД и медизделий |
| За | Заявка (в датах этапов — 9Зя) |
| S + код | Стоп на этом этапе: SВб, SПО, SАЦ, SПцКк, SКк, SПцР, SР |
| NКк | Есть контракт, не выбран для портфеля |

Этапа СЦ нет. Коды сравнивать после нормализации (кириллица/латиница в
похожих буквах, регистр, пробелы).

### Группы (состояние предложения)

| Группа | Коды |
|---|---|
| В работе | Вб, ПО, АЦ, ПцКк, ПцР |
| Контракт | Кк — **открытый вопрос**, см. DECISIONS |
| Результат | Р, Р-, За |
| Стоп | всё с приставкой S |
| Контракт, не в портфеле | NКк |
| Не распознан | всё остальное — показать в отчёте загрузки |

### Нормативы этапов (для «зависло»)

Вб, ПО, АЦ — 30 дней; ПцКк — 60; Кк — 90; ПцР — 365. «Зависло» — в
работе и дней в статусе (от «Дата Статуса» до даты выгрузки) больше
нормы. Нормативы вынести в настройки.

## Цены

- **Продукт** = МНН + форма + доза.
- **Цена завода** по умолчанию — последняя известная: Согл.Цена →
  Наша цена 2 → Наша цена 1 → Цена в USD. В интерфейсе меню «Цена»
  позволяет выбрать конкретную колонку.
- Цена только **за упаковку**. Цену за единицу не делать (пользователь
  отказался).
- **Мин / средняя (+ медиана) / макс** — по видимым после фильтров
  строкам, только одна валюта, без пустых цен.
- **«+X% к мин.»** — у каждого предложения относительно минимальной цены
  того же продукта среди видимых строк, если предложений по продукту ≥ 2.
  У самого дешёвого — пусто или «мин.». Метку «★ лучшая» **не делать**
  (пользователь попросил удалить).
- **Ценовой индекс завода** — средний «+X% к мин.» по его продуктам. Это
  формула из дизайна, пользователь её не подтвердил — см. DECISIONS.
- Остановленные (S) и NКк участвуют в сравнении цен, но показываются
  бледными. Возможна настройка «считать минимум только по активным».

## Что показывать в таблице «Все предложения»

МНН, Форма, Доза, Упаковка, Завод (+ страна завода), Для (страна), Цена
за уп., К мин., Статус (бейдж + название + дней в статусе), БДМ /
Аналитик, Последний комментарий (полный текст при наведении), Дата
статуса. Колонки скрываются через «Колонки», плотность строк, экспорт
отфильтрованного в Excel.

## Фильтры

Основные на виду: МНН (поиск с подсказками, «/» — фокус), Форма, Доза,
Статус, Для страны, Завод, «Только с ценой». Остальные под «Ещё
фильтры»: Состояние, Страна завода, БДМ, Аналитик, Категория. Списки
зависят друг от друга (выбрали МНН — в «Форме» только его формы).

Графиков на экране «Предложения» нет (пользователь просил убрать).
Аналитика — на отдельных экранах «Заводы», «Страны», «Воронка».
